# Agent 产出

本目录用于存放 agent 未经用户特别要求而生成的文档、报告、调查记录和中间材料。

## 放置规则

- 用户明确指定路径时，按用户指定位置保存。
- 未经特别要求的产出默认放在 `docs/agent/`。
- 不属于项目文档体系的内容不要放进 `docs/` 根目录或其他主题目录。
- 用户维护的资料（例如 `docs/drone/`）不要移动、修改或提交。

## 内容约定

- 文件名使用英文，正文使用中文。
- 文件开头说明生成目的、日期和依据的代码/数据版本。
- 临时验证数据、日志和截图不要长期提交；需要保留时放到单独子目录并在文末
  说明来源和清理方式。
- 经过确认、需要长期维护的内容应提升为主题文档，放到 `hardware/`、
  `simulation/`、`slam/` 等目录，并从本目录移除。

## 与正式文档的关系

`docs/README.md`、`docs/build_and_run.md` 和各主题目录是项目的正式文档；
本目录只保存一次性的或辅助性的产出。
